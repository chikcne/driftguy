# driftguy

A wasteland drift-survival game built with Godot 4. Your tyre smoke is the weapon: slide the car, engulf the raiders chasing you, collect their scrap, and bolt on upgrades.

See [godot-proto/README.md](godot-proto/README.md) for architecture, controls, and instructions on running on macOS or exporting to iOS.
